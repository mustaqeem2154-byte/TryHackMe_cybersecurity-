Linux Fundamentals Part 3

Overview

This room builds on Linux command-line skills and introduces additional tools and techniques useful for cybersecurity.

Topics Learned

* Linux processes and system information
* Managing users and permissions
* Basic automation and shell commands
* Working with system logs
* Understanding useful Linux utilities

Commands Practiced

ps

Displays information about running processes.

chmod

Changes file permissions.

sudo

Runs commands with elevated privileges when authorized.

man

Displays the manual for a command.

uname

Displays system information.

Cybersecurity Relevance

Linux administration skills are useful when investigating suspicious processes, checking permissions, and examining system activity.
