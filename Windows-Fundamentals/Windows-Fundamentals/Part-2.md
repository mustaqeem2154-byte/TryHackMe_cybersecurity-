Tools and Features

System Configuration (msconfig)

Helps configure Windows startup and troubleshoot system settings.

User Account Control (UAC)

Helps prevent unauthorized changes by requesting permission for certain administrative actions.

Computer Management

Provides access to administrative tools for managing a Windows computer.

Resource Monitor

Displays detailed information about CPU, memory, disk, and network usage.

Command Prompt

Allows users to interact with Windows using text-based commands.

Cybersecurity Relevance

These tools help analysts understand system configuration, investigate resource usage, and troubleshoot endpoint issues.
